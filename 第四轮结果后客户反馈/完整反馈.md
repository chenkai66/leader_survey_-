具体代码修改意见如下：

1. R 代码方向是对的，不要退回 lm()，也不要用 lavaan 假装处理嵌套。

现在使用 multilevel / nested model 的方向是正确的，后续请继续保留这种处理方式。

2. Model1 的 moderation 需要补完整。

现在代码里不能只跑某一条 interaction，例如只跑 Empowering × Power Distance → Benign Envy。

Model1 的 mediator equations 需要同时包含：

Autocratic × Narcissism → Benign Envy
Empowering × Narcissism → Benign Envy
Autocratic × Power Distance → Benign Envy
Empowering × Power Distance → Benign Envy
Autocratic × Narcissism → Malicious Envy

Autocratic × Power Distance → Malicious Envy
Empowering × Power Distance → Malicious Envy

也就是说，Narcissism 和 Power Distance 对 AL/EL → BE/ME 的 first-stage interactions 都要完整跑到。

不能只跑其中一条显著路径。

3. Model2 需要完整重跑。

Model2 不是只看 Benign Envy 和 Malicious Envy。

Model2 是 no controls 的 robustness model，所以它应该完整重复 Model1 的结构，只是删除 controls。

也就是说，Model2 也需要包括：

mediator equations
outcome equations
first-stage interactions
indirect effects
moderated indirect effects
对应的完整输出表格

不能只跑 X → M 部分。

4. Model3 需要保持和 Model1 一致，只替换 outcome source。

Model3 的核心逻辑是：

OCBS 和 CWBS 从 leader-rated 换成 follower-rated。

除此之外，其他设定应尽量与 Model1 保持一致。

所以 Model3 不应该额外加入新的 control，比如 WorkingYears_C。

如果 Model1 没有控制 WorkingYears_C，Model3 也不要突然加入。

否则 Model3 就变成了：

source robustness + extra control

这样 robustness comparison 不够干净。

5. Gender dummy 需要和我们表格口径一致。

我们之前确定的口径是：

male = 1，其他 = 0。

如果代码里现在使用的是 Gender_Female，请改成 Gender_Male，并确保编码方向与表格解释一致。

否则结果方向和解释容易反过来。

目前不能只计算少数几个 indirect effects，例如：

Autocratic → Malicious Envy → CWBS
Empowering → Benign Envy → Thriving

最终代码需要输出完整 indirect effects 和 conditional indirect effects。

至少要覆盖：

AL/EL → BE → Thriving
AL/EL → BE → OCBS
AL/EL → ME → Thriving
AL/EL → ME → CWBS

以及对应的 moderated indirect effects / conditional indirect effects。

主文 MCFA 保留核心构念即可，不需要把 PD、Narcissism、OCBS、CWBS 全部加进去。

但是 competing models 需要和 hypothesized model 保持同样的 within / between level logic。

也就是说：

如果 hypothesized model 里 leadership constructs 放在 between，BE / ME / Thriving 放在 within，那么 competing models 也应该保持这个层级逻辑。

不要在 competing models 里突然把所有构念都放到 both levels。

否则模型比较不够干净。
